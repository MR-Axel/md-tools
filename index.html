Free and open source. No account needed. Your files stay on your machine.

Edit the document you are reading.

Click a paragraph, a heading, a list item or a table cell and type. The Markdown is rewritten behind it, block by block.

Type **bold** or `code` and the marks turn into formatting. Start a line with #, - or > and it becomes a heading, a list or a quote.

Right-click a block.

Insert a table, a code block, a diagram, a formula or a callout below it. Turn it into a heading, move it, duplicate it or delete it.

Ctrl Z undoes it and Ctrl Y brings it back.

Diagrams with the drawing next to the code.

Click a Mermaid or Graphviz diagram and it opens with a live preview. Nine templates to start from. A syntax error shows under the last drawing that worked.

The whole folder, searchable.

The sidebar lists the files next to the one you opened and searches the text of all of them at once. Create, rename and delete files from there.

[[name]] links open the file with that name.

Cloud notes, sharing and a connection for your AISoon

Nothing goes to the cloud until you send it. Files on your disk and notes in the browser stay where they are.

The same notes on every device

Sign in with a six-digit code sent to your email. One click sends a note to the cloud, and it saves itself from then on.

Share a note or a folder

With another account, to read or to edit. You see who else has it open, and edits to different parts are merged. Or make a read-only public link with a password.

Let your AI read and write them

An MCP endpoint with five tools: list, read, write, append and search. Works with Claude and any other MCP client, with a token you create.

$ claude mcp add --transport http sharpmd https://sync.sharpmd.app/mcp \
    --header "Authorization: Bearer mdt_..."

Three pieces, all open source

The web app

Nothing to install. Chrome, Edge and Brave open folders and save in place. Firefox and Safari open one file at a time and saving downloads a copy.

Open the app

The extension

Works without a connection. Set Chrome as the default app for .md files and a double-click opens them rendered. It also renders Markdown served by a website.

Questions

Is SharpMD free?

The editor is free and open source, with no limit on files or on notes kept in the browser. Cloud notes are free up to 10.

How do I open a .md file with a double-click?

Install the extension, turn on "Allow access to file URLs" in its details, and set Chrome as the default app for .md files.

Which Markdown does it support?

GitHub Flavored Markdown, plus KaTeX math, Mermaid and Graphviz diagrams, footnotes, task lists, callouts, definition lists and YAML front matter.

Does it work without a connection?

The extension does. Cloud notes you have already opened also open offline, and what you write uploads when the connection is back.

How does my AI get to my notes?

You create a token in the app and add SharpMD as an MCP server in Claude or another client. It only sees the notes you keep in the cloud.

Your files are read in your browser.

No analytics. A note reaches the sync server only when you send it to the cloud. Privacy has the detail, and the code is on GitHub: the app under MIT, the server under AGPL.
