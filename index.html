Markdown notes your AI writes and your team reads.

A Markdown editor in the cloud, with the MCP endpoint already running. Claude, Codex or any other MCP client reads your notes before it works and writes down what it did. You edit on the formatted page, with no syntax to type.

Edit the document you are reading.

Click a paragraph, a heading, a list item or a table cell and type. The Markdown is rewritten behind it, block by block.

Type **bold** or `code` and the marks turn into formatting. Start a line with #, - or > and it becomes a heading, a list or a quote.

Right-click a block.

Insert a table, a code block, a diagram, a formula or a callout below it. Turn it into a heading, move it, duplicate it or delete it.

/ on an empty line opens the same menu. Ctrl Z undoes it and Ctrl Y brings it back.

Diagrams with the drawing next to the code.

Click a Mermaid or Graphviz diagram and it opens with a live preview. Start from a template, add steps and arrows with a button, and pick a color palette.

A mistake is explained in plain words, with its line marked. Formulas have an editor of the same kind.

The whole folder, searchable.

Open a folder from your disk and the sidebar lists its files, with how many notes each folder holds. The search box looks through the text of all of them at once.

Create, rename and delete from there, and move files and folders by dragging.

Your AI on the same notes

Claude, Codex or any other MCP client, working on the notes you keep in the cloud. It reaches as far as the token you give it.

  • Create a token in Settings and copy the instructions. Pasted into your AI, they carry the address, the token and how to write here.

  • Those instructions ask it to read the project notes before a task and to update them when it changes something. The next session starts from there, whichever AI it is.

  • Leave a comment on a paragraph. Your AI reads the open ones, makes each change and closes it with a reply.

  • Limit a token to a folder and nothing outside it can be read or written. Sharing is a separate permission, off unless you turn it on.

Cloud notes and sharingSoon

Nothing goes to the cloud until you send it.

  • Sign in with a six-digit code sent to your email, and your cloud notes are in the sidebar. One click sends a note there, and it saves itself from then on.

  • Open a session on a note and send the link. Guests join from the browser with a name, without an account, and everyone sees who is on each block.

  • With another account, to read or to edit. Or a read-only public link with a password.

  • Give a folder a password and it shows a lock. Its notes are encrypted in your browser before they are sent.

  • A deleted note waits there, and you can restore it.

Connect it to your tools

The notes your AI and your team write can start a flow in Make, n8n, Activepieces, Zapier or Slack, or receive from one.

  • SharpMD calls an address when a note or a card changes, for the whole account, one folder or one note. Paste a Slack or Discord address and the channel gets a readable line.

  • Each card carries its own fields, like due date, owner and priority. Moving it to another column sends card.moved, and finishing it sends card.done.

  • A secret address that adds a line to a note, creates a note or creates a card. A form or another system posts to it.

  • Notes, folders, search, history, comments and boards as JSON, with the same tokens as MCP. OpenAPI 3.1 included.

What the server can read, and what it cannot

  • Files on your disk

    They are read in your browser and never uploaded. No account and no analytics.

  • Notes in the cloud

    Stored encrypted. The server holds that key, because it has to share them and hand them to your AI.

  • Folders with a password

    Encrypted end to end: the server stores text it cannot read. Your AI gets in only while you unlock the folder, for the time you set.

The detail is in Privacy, and the code is on GitHub: the app under MIT, the server under AGPL.

Server source

On sharpmd.app it is already running

We run the accounts, the sign-in mail, the backups, the updates and the MCP endpoint over HTTPS. You sign in and paste one message into your AI.

On your own server it is the same code

You set up the domain with HTTPS, a mailer for the sign-in codes, the encryption key, the backups and each update, and then type its address in Settings. The steps are in the server README.

Questions

Something else? Write to hello@sharpmd.app.

What is free and what is paid?

The editor is free and open source, with no limit on files or on notes kept in the browser, and 10 notes in the cloud. The paid plan, USD 3.99 a month or USD 39 a year, covers what runs on our server: unlimited cloud notes, sharing, live sessions, a published site, the connection for your AI, the API and webhooks, and version history.

Does SharpMD come with its own AI?

No. You connect the one you already use: Claude, Codex or any other MCP client. SharpMD gives it your notes and the tools to read and write them.

How does my AI get to my notes?

You create a token in the app and add SharpMD as an MCP server in Claude or another client. It only sees the notes you keep in the cloud, or one folder if you limit the token.

How is it different from a local editor with plugins?

A local editor keeps the notes on one machine. To share them or reach them from an AI you add plugins and a sync service, and each person repeats the setup. SharpMD opens in the browser with the sharing, the MCP endpoint and the API already running. A file on your disk still opens without being uploaded.

Can the server read my notes?

Cloud notes are stored encrypted on the server, which holds the key so it can share them and serve your AI. A folder you protect with a password is different: it is encrypted in your browser and nobody else can read it. To let your AI in, you unlock that folder for a set time. If you lose the password and the backup key, those notes cannot be recovered.

Can several people edit a note at once?

Open a live session on a cloud note and send the link. Up to 12 people write at once. You end the session when you want, or make a new link to leave the old one out.

What happens to a cloud note I delete?

It stays in the trash for 30 days and you can restore it. While it is there it is not searched, shared or reachable by your AI.

Does it work without a connection?

Yes. The extension always does, and the web app does once you have opened it. Cloud notes you have already opened are there too, and what you write uploads when the connection is back.

Which Markdown does it support?

GitHub Flavored Markdown, plus KaTeX math, Mermaid and Graphviz diagrams, footnotes, task lists, callouts, definition lists and YAML front matter.

How do I open a .md file with a double-click?

Install the extension, turn on "Allow access to file URLs" in its details, and set Chrome as the default app for .md files.
