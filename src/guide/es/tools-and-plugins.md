# Herramientas y plugins

Son dos pestañas de **Ajustes**.

## Plugins

Un plugin decide qué sintaxis de Markdown se dibuja: tablas, tareas, notas al pie, fórmulas, diagramas, avisos, enlaces `[[nombre]]`. Casi todos vienen prendidos. Cada uno muestra un ejemplo dibujado con el plugin apagado y prendido.

Apagar un plugin no cambia tus notas. Solo cambia cómo se ven.

## Herramientas

Una herramienta suma una función entera a la app. Vienen apagadas, salvo el tablero kanban. El código de cada una se pide recién cuando la prendés.

| Herramienta | Qué hace |
|---|---|
| **Leer en voz alta** | Lee la nota con las voces de tu dispositivo |
| **Dictado** | Escribís hablando |
| **Tablero kanban** | Un bloque `kanban` se ve como tablero. Viene prendida |
| **Modo presentación** | La nota como diapositivas a pantalla completa |
| **Nota diaria** | Abre la nota de hoy o la crea desde una plantilla |
| **Exportar a Word** | Suma Word (.docx) al menú **Exportar** |
| **Mapa de enlaces** | Un grafo de qué notas enlazan a cuáles |
| **Diagramas explorables** | Un diagrama de flujo que se recorre |
| **JSON y YAML** | Un bloque o un archivo de datos como árbol que se edita |
| **Importar a Markdown** | Convierte Word, Excel, PowerPoint, EPUB, PDF, HTML y CSV en una nota |
| **Asistente de IA (con tu clave)** | Reescribe, genera y responde con tu propia clave |
| **Agentes** | Muestra en vivo los agentes que tu IA registró por MCP |
| **Servidores locales**, **Worktrees** y **Sesiones locales** | Leen de un programa que corrés en tu computadora |

En la misma pestaña está **Comunidad**: plantillas, temas y paletas de diagramas que compartió otra gente, revisados antes de publicarse. Son contenido, nunca código. Lo que sumás queda en tu dispositivo.
