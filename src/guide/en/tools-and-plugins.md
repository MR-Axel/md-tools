# Tools and plugins

They are two tabs in **Settings**.

## Plugins

A plugin decides which Markdown syntax is drawn: tables, tasks, footnotes, formulas, diagrams, callouts, `[[name]]` links. Almost all of them come turned on. Each one shows an example drawn with the plugin off and on.

Turning a plugin off does not change your notes. It only changes how they look.

## Tools

A tool adds a whole feature to the app. They come turned off, except the kanban board. The code of each one is requested only when you turn it on.

| Tool | What it does |
|---|---|
| **Read aloud** | Reads the note with the voices of your device |
| **Dictation** | You write by speaking |
| **Kanban board** | A `kanban` block shows as a board. It comes turned on |
| **Presentation mode** | The note as full screen slides |
| **Daily note** | Opens today's note or creates it from a template |
| **Export to Word** | Adds Word (.docx) to the **Export** menu |
| **Link map** | A graph of which notes link to which |
| **Explorable diagrams** | A flowchart you can walk through |
| **JSON and YAML** | A data block or file as a tree you can edit |
| **Import to Markdown** | Turns Word, Excel, PowerPoint, EPUB, PDF, HTML and CSV into a note |
| **AI assistant (your key)** | Rewrites, generates and answers with your own key |
| **Agents** | Shows live the agents your AI registered over MCP |
| **Local servers**, **Worktrees** and **Local sessions** | They read from a program you run on your computer |

The same tab has **Community**: templates, themes and diagram palettes shared by other people, reviewed before they are published. They are content, never code. What you add stays on your device.
