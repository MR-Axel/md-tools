# Keyboard shortcuts

The full sheet is inside the app. It opens with `?`, or with `Ctrl+/` while you type. It is also in **Settings** > **Advanced** > **Keyboard shortcuts**.

On a Mac, `Ctrl` is `⌘` and `Alt` is `⌥`. The app shows them that way.

## Everyday ones

| Shortcut | What it does |
|---|---|
| `Ctrl+S` | Save |
| `Ctrl+Z` and `Ctrl+Y` | Undo and redo |
| `Ctrl+B` and `Ctrl+I` | Bold and italic |
| `Ctrl+K` | Insert or edit a link |
| `Ctrl+Shift+F` | Search the note or the folder |
| `Ctrl+P` | Print or save as PDF |
| `F2` | Rename the note |
| `Esc` | Close a menu, a dialog or the search box |

## While writing

| Shortcut | What it does |
|---|---|
| `Enter` | Close the block and open another one below |
| `Shift+Enter` | Line break |
| `Tab` and `Shift+Tab` | In a table, next or previous cell. In a list, indent an item or take it out one level |
| `Alt+↑` and `Alt+↓` | Move a list item, or the selected blocks |
| `Ctrl+D` | Duplicate the selected blocks |
| `[[` | Link another note |

## View

| Shortcut | What it does |
|---|---|
| `Alt+Shift+T` | Switch the theme |
| `Alt+Shift+F` | Fold or unfold the section of the cursor |
| `Alt+Shift+B` | Show or hide the sidebar, with the extension |
| `Alt+Shift+C` | Center the content or not, with the extension |

## With a tool turned on

| Shortcut | Tool |
|---|---|
| `Alt+Shift+S` | **Read aloud** |
| `Alt+Shift+D` | **Dictation** |
| `Alt+Shift+P` | **Presentation mode** |
| `Alt+Shift+H` | **Daily note** |
| `Alt+Shift+G` | **Link map** |
| `Alt+Shift+A` and `Alt+Shift+Q` | **AI assistant (your key)** |

The tools are in [Tools and plugins](tools-and-plugins.md).
