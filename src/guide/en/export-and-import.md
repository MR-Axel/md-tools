# Export and import

## Taking a note with you

The **Export** button in the top bar offers:

| Option | What comes out |
|---|---|
| **PDF** | The note through the print dialog of the browser |
| **HTML file** | One file that opens in any browser |
| **Markdown file (.md)** | The text of the note |
| **Print** | The same as `Ctrl+P` |

The **Copy** button copies the note as **Markdown**, **Formatted text** or **HTML**. Formatted text pastes well into an email or a document.

With the **Export to Word** tool turned on, the menu adds Word (.docx). The file is built in your browser, with the headings, lists, tables, code and images. Formulas go as LaTeX text.

## A whole folder

In the explorer, a right-click on a folder offers **Export the folder…**. It puts all its notes into one document, one after another: PDF, HTML, Word or a single Markdown file. Links between the notes become internal, and you can add a cover and a table of contents.

## Bringing in other formats

The **Import to Markdown** tool turns a file into a note:

- Word (.docx), Excel (.xlsx) and PowerPoint (.pptx)
- EPUB and PDF
- HTML, CSV and TSV

It all happens in your browser and nothing is uploaded. The result opens as a new unsaved note, or goes at the end of the open note.

> [!NOTE]
> From a PDF only the text comes out, page by page. There is no text recognition in images.

Both tools are turned on in **Settings** > **Tools**. See [Tools and plugins](tools-and-plugins.md).

## Your files stay yours

A note is a `.md` file. What you write in a folder on disk is already there, with nothing to export. A browser note is saved as a file with `Ctrl+S`.
