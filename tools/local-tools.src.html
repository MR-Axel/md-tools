SharpMD Local: your dev servers, worktrees and agent sessions

A small program that runs on your computer and tells SharpMD three things a web page cannot see by itself: what is listening on which port, the state of your git worktrees, and which AI agent sessions are open. It is free and open source.

It listens on 127.0.0.1 only. Nothing leaves your computer and nothing goes through our servers.

What it shows

  • Local servers. Every port that is listening, with its process, its project, the version it runs and since when. What was started from a project folder can be closed from there.
  • Worktrees. For the folders you choose: branch, last commit, uncommitted changes, last edit and what is working in each one. It only looks: it deletes and changes nothing.
  • Local sessions. The AI agent sessions open on the computer, Claude Code and the ones you set up, with their title, project and the memory each one uses.
  • Show in Explorer. In the app, the menu of a file from your disk opens the system file manager with that file selected.

What it does not do

  • It runs no command that comes from outside, and it returns no file contents.
  • It closes nothing from the system and no installed program. Only dev servers and agent sessions it recognised by itself, and only after you confirm.
  • It looks at no folder you did not add.
  • It installs no service and does not start by itself. If you do not open it, it is not running.

Install it

It needs Node.js 22 or newer and nothing else. It lives in the local folder of the SharpMD repository.

git clone https://github.com/SharpMD/sharpmd.git
cd sharpmd/local
node bin/sharpmd-local.js

Without git: download the repository as a ZIP from GitHub, unzip it and, on Windows, double-click start.cmd inside local.

There is no installer yet. To stop it, press Ctrl+C in its console or close the window.

Pair it with SharpMD

  1. When it starts, the program prints a pairing code.
  2. In SharpMD, open Settings > Tools and turn on Local servers, Worktrees or Local sessions.
  3. Paste the code and press Pair. The browser asks once whether the site may connect to this computer: allow it.

The code stays in that browser. The three tools share it.

Chrome, Edge and Firefox connect once you allow it. Safari blocks a page from reaching 127.0.0.1: there, use the panel the program serves itself, at the address it prints when it starts.

Choose your folders

It starts with none. Add the folders it may look at from the console:

node bin/sharpmd-local.js folders add C:\code

A folder can be a repository or a folder with repositories inside. Worktrees come from there, and Show in Explorer only works for files inside those folders.

How it is protected

  • It listens on this computer only, never on the network.
  • Every request needs the pairing code, a random 256-bit token kept in a file only your user reads.
  • It answers only to SharpMD: any other site is refused, even with the code.
  • To close something, the request has to match what the program sees at that moment: the process, its port and when it started.
  • A path is shown only if it is an existing file inside a folder you added, and the file manager is the only thing it opens.

The full table, with what it does not cover, is in the README of the program.

SharpMD Local: tus servidores, worktrees y sesiones de agentes

Un programa chico que corre en tu computadora y le cuenta a SharpMD tres cosas que una página web no puede ver sola: qué está escuchando en cada puerto, cómo están tus worktrees de git y qué sesiones de agentes de IA hay abiertas. Es gratis y de código abierto.

Escucha solo en 127.0.0.1. Nada sale de tu computadora y nada pasa por nuestros servidores.

Qué muestra

  • Servidores locales. Cada puerto que está escuchando, con su proceso, su proyecto, la versión que corre y desde cuándo. Lo que se lanzó desde una carpeta de proyecto se puede cerrar desde ahí.
  • Worktrees. De las carpetas que elijas: rama, último commit, cambios sin confirmar, última edición y qué está trabajando en cada uno. Solo mira: no borra ni cambia nada.
  • Sesiones locales. Las sesiones de agentes de IA abiertas en la computadora, Claude Code y las que configures, con su título, su proyecto y la memoria que usa cada una.
  • Mostrar en el Explorador. En la app, el menú de un archivo de tu disco abre el explorador de archivos del sistema con ese archivo seleccionado.

Qué no hace

  • No ejecuta ningún comando que le llegue de afuera, ni devuelve el contenido de ningún archivo.
  • No cierra nada del sistema ni programas instalados. Solo servidores de desarrollo y sesiones de agentes que reconoció por su cuenta, y recién cuando confirmás.
  • No mira ninguna carpeta que no hayas sumado.
  • No instala ningún servicio ni arranca solo. Si no lo abrís, no corre.

Instalarlo

Necesita Node.js 22 o más nuevo y nada más. Vive en la carpeta local del repositorio de SharpMD.

git clone https://github.com/SharpMD/sharpmd.git
cd sharpmd/local
node bin/sharpmd-local.js

Sin git: bajá el repositorio como ZIP desde GitHub, descomprimilo y, en Windows, hacé doble clic en start.cmd dentro de local.

Todavía no hay instalador. Para apagarlo, Ctrl+C en su consola o cerrar la ventana.

Emparejarlo con SharpMD

  1. Al arrancar, el programa muestra un código de emparejamiento.
  2. En SharpMD, abrí Ajustes > Herramientas y prendé Servidores locales, Worktrees o Sesiones locales.
  3. Pegá el código y tocá Emparejar. El navegador pregunta una vez si el sitio puede conectarse con esta computadora: permitilo.

El código queda en ese navegador. Las tres herramientas lo comparten.

Chrome, Edge y Firefox se conectan una vez que lo permitís. Safari no deja que una página llegue a 127.0.0.1: ahí usá el panel que sirve el propio programa, en la dirección que muestra al arrancar.

Elegir tus carpetas

Arranca sin ninguna. Las carpetas que puede mirar se suman desde la consola:

node bin/sharpmd-local.js folders add C:\code

Una carpeta puede ser un repositorio o una carpeta con repositorios adentro. De ahí salen los worktrees, y Mostrar en el Explorador solo funciona con archivos de esas carpetas.

Cómo está protegido

  • Escucha solo en esta computadora, nunca en la red.
  • Cada pedido necesita el código de emparejamiento, un token al azar de 256 bits guardado en un archivo que solo lee tu usuario.
  • Solo le contesta a SharpMD: cualquier otro sitio queda rechazado, aunque tenga el código.
  • Para cerrar algo, el pedido tiene que coincidir con lo que el programa ve en ese momento: el proceso, su puerto y cuándo arrancó.
  • Una ruta se muestra solo si es un archivo que existe dentro de una carpeta que sumaste, y el explorador de archivos es lo único que abre.

La tabla completa, con lo que no cubre, está en el README del programa.
