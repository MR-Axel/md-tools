A WYSIWYG Markdown editor online: edit Markdown without typing syntax

Click a heading, a table or a diagram and change it right there, on the formatted page. The file is still plain Markdown.

Open the app

Free and open source. Nothing to install, and no account needed to write.

You edit the element itself

Click a paragraph, a heading, a list item or a table cell and type. Right-click a block to insert a table, a code block, a diagram, a formula or a callout below it, or to turn it into a heading, move it, duplicate it or delete it.

/ on an empty line opens the same menu.

Tables, tasks, formulas and diagrams

  • Tables get rows and columns with a button, and a row that sums each column.
  • A task list turns into a board: columns with cards you drag.
  • Formulas have an editor with live preview and buttons for fractions, sums and symbols.
  • A Mermaid or Graphviz diagram opens with the drawing next to the code. You add steps and arrows with a button.

The file stays plain Markdown

The Markdown is rewritten behind the page, block by block, and the source is one click away. If you like the syntax, type **bold** or start a line with # and the marks turn into formatting.

It reads GitHub Flavored Markdown, plus KaTeX math, Mermaid and Graphviz diagrams, footnotes, task lists, callouts, definition lists and YAML front matter.

Your files open without being uploaded

A .md file or a folder on your disk is read in your browser and never uploaded. Chrome, Edge and Brave open folders and save in place. Firefox and Safari open one file at a time, and saving downloads a copy.

With a folder open, the sidebar lists its files and the search box looks through the text of all of them at once.

No account, and no connection needed

The editor asks for no account, with no limit on files or on notes kept in the browser. The web app opens without a connection once you have used it, and the extension always does.

Web app, Chrome extension and phone

The web app runs in the browser with nothing to install. With the extension, set Chrome as the default app for .md files and a double-click opens them rendered. On the phone the web app fits a small screen and installs from the browser, and the Android app is that same app in a package.

Un editor de Markdown WYSIWYG online: editá Markdown sin escribir sintaxis

Hacés clic en un título, una tabla o un diagrama y lo cambiás ahí mismo, sobre la página ya formateada. El archivo sigue siendo Markdown plano.

Abrir la app

Gratis y de código abierto. No hay nada que instalar ni hace falta una cuenta para escribir.

Editás sobre el propio elemento

Hacés clic en un párrafo, un título, un ítem o una celda y escribís. Con clic derecho sobre un bloque insertás debajo una tabla, un bloque de código, un diagrama, una fórmula o un aviso, o lo convertís en título, lo movés, lo duplicás o lo eliminás.

/ en una línea vacía abre el mismo menú.

Tablas, tareas, fórmulas y diagramas

  • Las tablas suman filas y columnas con un botón, y tienen una fila que suma cada columna.
  • Una lista de tareas pasa a ser un tablero: columnas con tarjetas que arrastrás.
  • Las fórmulas tienen un editor con vista previa en vivo y botones para fracciones, sumatorias y símbolos.
  • Un diagrama Mermaid o Graphviz se abre con el dibujo al lado del código. Sumás pasos y flechas con un botón.

El archivo sigue siendo Markdown plano

El Markdown se reescribe por detrás de la página, bloque por bloque, y el código está a un clic. Si te gusta la sintaxis, escribís **negrita** o empezás una línea con # y los signos se vuelven formato.

Lee GitHub Flavored Markdown, más matemática con KaTeX, diagramas Mermaid y Graphviz, notas al pie, listas de tareas, avisos, listas de definición y cabecera YAML.

Tus archivos abren sin subirse

Un archivo .md o una carpeta de tu disco se lee en tu navegador y nunca se sube. Chrome, Edge y Brave abren carpetas y guardan en el lugar. Firefox y Safari abren de a un archivo, y al guardar descargan una copia.

Con una carpeta abierta, la barra lateral muestra sus archivos y el buscador revisa el texto de todos a la vez.

Sin cuenta y sin conexión

El editor no pide cuenta, y no hay límite de archivos ni de notas guardadas en el navegador. La app web abre sin conexión una vez que la usaste, y la extensión siempre.

App web, extensión de Chrome y celular

La app web corre en el navegador sin nada que instalar. Con la extensión, ponés Chrome como programa por defecto para los .md y con doble clic se abren ya formateados. En el celular la app web entra en pantalla chica y se instala desde el navegador, y la app de Android es esa misma app empaquetada.
